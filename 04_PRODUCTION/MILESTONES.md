# MILESTONES

_Concrete milestones, from OBJECTIVES and ROADMAP._

- **M0. Foundation (done):** research + decision repository.
- **M1. Concept + spec:** concept chosen (with Jonathan), `../02_GAME_DESIGN/GREYBOX_SPEC.md` written, Unity project created.
- **M2. Playable greybox (~1 week):** core loop + multiplayer in grey boxes, tested by two. Go/no-go: is it fun?
- **M3. Sortable build (~2 weeks):** stable core, playable multiplayer, enough content, appropriate visuals, audio, basic UI, working build pipeline, no critical blockers.
- **M4. Steam release (~1 month after M3):** store page, trailer, wishlists, playtests, polish, launch.

Each milestone has a clear exit test (`../00_PROJECT/SUCCESS_CRITERIA.md`).
