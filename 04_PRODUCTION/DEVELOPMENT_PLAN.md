# DEVELOPMENT PLAN

_How we move, concretely. The production order is in `00_PROJECT/ROADMAP.md`._

## Current phase: concept to greybox
1. Concept brainstorm with Spykernv. Output: 1 (or 2) locked concept(s) + an ADR.
2. Fill the minimal design: GAME_CONCEPT, CORE_LOOP, GAME_RULES, MECHANICS, SYSTEMS, PLAYER_EXPERIENCE (and nothing else for now).
3. Write `02_GAME_DESIGN/GREYBOX_SPEC.md`: scene, players, objects, interactions, systems, temporary UI, win and lose conditions, networking, tests, and what is explicitly out of scope.
4. Create Unity (Built-in RP, git already in place, MCP wired), then ask: "Create the greybox according to GREYBOX_SPEC.md".
5. Play. Bad, back to design (no 3D). Fun, lock the core.
6. Only then: 3D generation / Blender / Asset Store / textures / audio.

## Method rule
Prototype competing concepts if possible. Do not invest two weeks in the first concept just because it was first.
