# CHEATING

_How much we care, and what we do. For a friends-first co-op game: not much, at first._

## Position
- Co-op over Steam P2P with friends: cheating is low-stakes; a cheater mostly ruins their own lobby.
- Host-authority already blocks the crudest client-side cheats.
- No anti-cheat middleware (cost, complexity) unless the concept has competitive stakes.
- If any hidden-role / social element exists, protect **hidden information** on the host side so clients cannot read what they should not.

## Rule
Do not build anti-cheat infrastructure for a co-op party game. Protect only the information the game depends on.
