# THIRD PARTY

_Policy for external packages and assets. Bias to few, proven, free._

## Rules
- Prefer first-party Unity packages (Input System, URP, Test Framework) and Steamworks.
- A paid asset or plugin is justified only when it saves substantial time vs building it (`../08_BUSINESS/COST_MODEL.md`).
- Check licenses for commercial use before adopting anything (assets, SFX, fonts).
- Networking: prefer an established Steam / Unity solution over custom infrastructure (risk R2).
- Record every third-party dependency and its license here as we add it.

(none beyond Unity, plus planned Steamworks)
