# RELEASE PLAN

_The plan for shipping. Ties ROADMAP M4 to concrete steps._

## Sequence
1. Sortable build validated (M3).
2. Steam page, capsules, trailer live; wishlists accumulating.
3. Steam Playtest round; fix what it surfaces.
4. Release candidate: QA (`QA.md`), performance, no critical blockers.
5. Steam submission and review (`STEAM_SUBMISSION.md`).
6. Launch: creator coverage, discount, community presence.
7. Post-launch support and analysis (`POST_LAUNCH.md`).

## Rule
The timeline is aggressive but does not justify shipping broken (OBJECTIVES).
