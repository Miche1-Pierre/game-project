# QA

_Final quality pass before release._

## Focus
- No critical or progression-blocking bugs.
- Multiplayer edge cases (join, leave, host drop) handled.
- Performance acceptable on the baseline machine.
- Onboarding and basic UX are clear.
- Funny bugs triaged, keep the good ones (`../11_TESTING/BUG_POLICY.md`).

## Rule
Reserve explicit time for QA; do not spend the whole schedule on features (risk R14).
