# STEAM SETUP

_Getting onto Steam. Process, done after the core is validated._

## Steps
1. Steamworks partner account (Steam Direct, ~$100, `../08_BUSINESS/COST_MODEL.md`).
2. Create the app, get the AppID (`APP_ID.md`).
3. Configure depots, build upload, store page (`STORE_PAGE.md`).
4. Set up Steam Playtest (`STEAM_PLAYTEST.md`) for testing.
5. Integrate Steamworks SDK (lobbies, P2P, invites; voice if used).

## Rule
Nothing on Steam before the core is validated in greybox (`STEAM_STRATEGY.md`).
