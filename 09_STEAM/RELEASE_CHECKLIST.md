# RELEASE CHECKLIST (Steam)

_Steam-side launch checklist. Production readiness: `../04_PRODUCTION/RELEASE_CHECKLIST.md`._

## Before launch
- [ ] Store page live with capsules, screenshots, trailer, description, tags.
- [ ] Build uploaded to the default branch, runs clean from a fresh install.
- [ ] Depots and launch options configured.
- [ ] Price and regional pricing set.
- [ ] Steamworks features tested (lobbies, P2P, invites, voice if used).
- [ ] Wishlists accumulated; launch discount decided.
- [ ] Steam Playtest results addressed.
- [ ] Release date and time set; store visible.
